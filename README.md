## Before publishing
1. Open `index.html`.
2. Replace `your-email@example.com` with your real contact email.
3. Edit project descriptions or links if needed.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `portfolio`.
2. Upload all files from this folder (not the ZIP itself).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`, then save.

For a personal root site, name the repository `danny234.github.io`.
